## 🎮 玩法說明（結局與時長）
參考 *Tap Titans* 製作的微放置型 RPG。玩家透過點擊螢幕擊敗怪物獲得金錢並升級，最終目標是打敗各樓層的主宰通關！

* **遊玩時長：** 5 分鐘 ~ 1 小時
* **普通結局：** 擊敗最後一層樓主 (F5)
* **壞結局：** ？？？
* **隱藏結局：** ？？？

## 🎒 玩家道具說明
* 🪙 **ゴールド / 金幣：** 用以升級玩家角色、提升等級與交換（可兌換夢之碎片 & 夢之神隨等）。
* 🔮 **夢の欠片 / 夢之碎片：** 用以召喚/抽取夥伴，協助進行戰鬥與通關遊戲。
* 💎 **鑑定物 / 商店碎片：** 用以解鎖神器，大幅增強玩家能力。
* 🧬 **夢の神髄 / 夢之神隨：** 用以解鎖夢境神主，帶來強大的能力加成。

## 🖥️ 介面功能介紹

### 🛑 上方主介面
* **夢之星圖：** 用以切換每個樓層，方便玩家在不同關卡間穿梭。
* **進度一覽：** 查看玩家目前各項數值（玩家傷害 / 夥伴傷害 / 金錢持有 / 碎片持有 / 蒐集進度）。
* **特權：** 遊戲內置金手指，可用於加速玩家的遊玩進度。

### 📱 下方操作面板
* **強化：** 升級玩家本身數值，直接增加點擊傷害。
* **圖鑑：** 查看當前樓層的夥伴蒐集進度與詳細資訊。
* **扭蛋：** 可抽取不同樓層的夥伴協助戰鬥，是解鎖不同結局的關鍵！
  * ➔ **碎片溶解：** 用以溶解多餘的夥伴碎片，並轉換為【商店碎片】。
  * ➔ **夢境交易所：** 提供資金與物資轉換（金錢 ⇄ 夢境碎片、金錢 ⇄ 夢境神隨）。
* **夢之主：** 用以提升玩家核心能力與獲得各項數值加成。
* **神器 (商店)：** 用以大幅提升玩家能力，引導走向不同的結局線。

## 🏆 成就系統一覽
全遊戲共有 **18 個成就** 供玩家探索遊玩！（包含 12 個普通成就 / 6 個隱藏成就）
* *普通成就：* 遊戲結束時不管有無達成，都會顯示解鎖條件。
* *隱藏成就：* 必須在完全解鎖後，才會顯示獲得條件。
