## 🎮 プレイ方法（エンディングとプレイ時間）
*Tap Titans* を参考にした、お手軽な放置系RPGです。画面をタップしてモンスターを倒し、お金を稼いでレベルアップしながら、各階層のボス（楼主）を倒してクリアを目指します！

* **プレイ時間：** 5分～1時間程度
* **ノーマルエンド：** 最終階層のボス（F5）を撃破する

## 🎒 プレイヤーアイテム説明
* 🪙 **ゴールド：** プレイヤーのレベルアップや、夢の欠片・夢の神髄などとの交換に使用します。
* 🔮 **夢の欠片：** 仲間の召喚・ガチャに使用し、戦闘やステージ攻略をサポートしてもらいます。
* 💎 **鑑定物：** 神器の解放に使用し、プレイヤーの能力を大幅に強化します。
* 🧬 **夢の神髄：** 夢境神主の解放に使用し、強力なステータスボーナスを獲得します。

## 🖥️ インターフェース紹介

### 🛑 画面上部 UI
* **夢の星図：** 各階層を切り替え、プレイヤーが自由にステージを移動できるようにします。
* **進捗一覧：** 現在のステータスを確認できます。（プレイヤーDPS／仲間DPS／所持金／所持欠片／収集進度など）
* **特権：** ゲーム内チート機能。プレイ進度を加速させることができます。

### 📱 画面下部 UI
* **強化：** プレイヤー自身のステータスを上げ、タップダメージを増加させます。
* **図鑑：** 現在ステージの仲間の収集進度や詳細情報を確認できます。
* **ガチャ：** 各階層の仲間を引くことができます。戦闘のサポートや、異なるエンドの分岐点となります。
  * ➔ **欠片溶解：** 余った仲間の欠片を溶解し、「鑑定物」に変換します。
  * ➔ **夢境取引所：** お金 ⇄ 夢の欠片、お金 ⇄ 夢の神髄の相互交換を行います。
* **夢の主：** プレイヤーのコア能力向上や、各種ステータスボーナスを獲得します。
* **神器（ショップ）：** プレイヤーの能力を大幅に引き上げ、様々なエンディングへ導きます。

## 🏆 実績システム一覧
全18個の実績が用意されています！（通常実績12個／隠し実績6個）
* *通常実績：* ゲーム終了時、達成未達成に関わらず解放条件が表示されます。
* *隠し実績：* 実際に解放されるまで獲得条件は秘匿されます。

### 📈 プレイヤーレベル系
* **ちょい旅** `[銅]`：プレイヤーレベル5達成。
* **軌道に乗る** `[銀]`：プレイヤーレベル15達成。
* **夢を破る者** `[金]`：プレイヤーレベル最大（25）達成。
* **億万長者** `[隠し]`：？？？

### 仲間・絆系
* **一人じゃない** `[銅]`：仲間を1人以上解放。
* **共に歩む** `[銀]`：仲間の数が10人突破。
* **夢の旅人** `[金]`：仲間をコンプリートする。
* **無限スロット** `[隠し]`：？？？

### 🌌 神主覚醒系
* **恍惚たる夢** `[銅]`：神主を1人以上解放。
* **人生は夢の如し** `[銀]`：すべての神主を解放。
* **夢を舞う者** `[金]`：すべての神主を解放し、最大レベル（6）まで強化。
* **選ばれし者** `[隠し]`：？？？

### ⚔️ 神器鍛造系
* **神器錬成** `[銅]`：神器を1つ以上解放。
* **鍛冶の天才** `[銀]`：神器を3つ以上解放。
* **夢を織る者** `[金]`：すべての神器を解放。
